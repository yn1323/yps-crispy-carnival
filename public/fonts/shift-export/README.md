# Shift export font

`NotoSansJP-Regular.ttf` is a static Regular (weight 400) instance of Noto Sans JP from Google Fonts.
The font is distributed under the SIL Open Font License 1.1 in `OFL.txt`, which permits redistribution and document embedding.

Source: https://github.com/google/fonts/tree/main/ofl/notosansjp

Downloaded: 2026-09-05

The source `NotoSansJP[wght].ttf` was instantiated with fontTools 4.64.0 (`instantiateVariableFont(font, {"wght": 400}, inplace=True, updateFontNames=True)`) for PDF renderer compatibility. No glyphs were removed.

Source SHA-256: `c2f3b4d463500a2ddcd3849cded1fceeb9fd6d1c32e6cbecd568453ba50fc68f`

The preview and PDF generator load this local asset on demand. They do not send report content to a font service.
Excel uses the font name `Noto Sans JP`; the font must be installed on the computer opening the workbook to display it without substitution.
