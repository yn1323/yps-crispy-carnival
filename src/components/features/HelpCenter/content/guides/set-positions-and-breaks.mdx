勤務をホールやキッチンなどのポジションに分け、休憩時間もシフト表に残せます。
スタッフは確定シフトで、自分のポジションと休憩の時間を確かめられます。

ポジションは必要人数設定で作り、シフト表の「くわしく」表示で勤務に割り当てます。

## ポジションを作る

1. シフトリホームで、店舗名の右にある歯車のボタンを押します。

   <HelpFigure
     src="../images/set-positions-and-breaks/home-shop-detail.webp"
     alt="シフトリホームで、店舗名の右にある店舗詳細のボタンを枠で示した画面"
     width={1280}
     height={520}
   />

2. 店舗の詳細の「シフト作成」にある**必要人数設定**を押します。

   <HelpFigure
     src="../images/set-positions-and-breaks/shop-detail-setup.webp"
     alt="店舗の詳細の「シフト作成」にある「必要人数設定」を枠で示した画面"
     width={1280}
     height={760}
   />

3. 「ポジション」の右にある**ポジションを追加する**を押します。すでにポジションがある店舗では、同じ場所の**ポジションを編集する**を押します。

   <HelpFigure
     src="../images/set-positions-and-breaks/positions-add.webp"
     alt="ポジションがまだない店舗の必要人数設定で、「ポジションを追加する」を枠で示した画面"
     width={1280}
     height={520}
   />

   <HelpFigure
     src="../images/set-positions-and-breaks/positions-edit.webp"
     alt="ポジションがある店舗の必要人数設定で、「ポジションを編集する」を枠で示した画面"
     width={1280}
     height={520}
   />

4. **ポジションを追加**を押し、名前を入力して色を選びます。

   <HelpFigure
     src="../images/set-positions-and-breaks/position-dialog.webp"
     alt="「ポジションを編集」の画面で、「ポジションを追加」を枠で示した画面"
     width={592}
     height={479}
   />

ポジションは10件まで作れます。

## シフト表を「くわしく」表示にする

表示を切り替えると、開いている募集の下書きの勤務が消えます。スタッフが提出した希望は残ります。

1. ポジションを割り当てる募集のシフト表を開きます。
2. **表示設定**を押し、**くわしく**を選びます。

   <HelpFigure
     src="../images/set-positions-and-breaks/display-settings.webp"
     alt="シフト表の「表示設定」のメニューで、「くわしく」を枠で示した画面"
     width={1280}
     height={340}
   />

## PCで設定する

時間指定の募集では勤務のバーを横にドラッグして範囲を決め、開いたメニューでポジションか休憩を選びます。

<HelpVideo
  src="../videos/set-positions-and-breaks/pc-range-assign.mp4"
  title="勤務のバーをドラッグしてポジションと休憩を設定する"
  width={1920}
  height={1080}
/>

1. 日付の見出しの右に並ぶボタンで、ポジションを選びます。

   <HelpFigure
     src="../images/set-positions-and-breaks/insert-palette.webp"
     alt="シフト表の日付の見出しの右に並ぶ、ポジションと休憩のボタンを枠で示した画面"
     width={1280}
     height={300}
   />

2. 勤務のない所を横にドラッグします。選んだポジションで勤務が追加されます。
3. ポジションを変える場合は、勤務のバーを横にドラッグし、メニューでポジションを選びます。
4. 勤務の一部を休憩にする場合は、その時間を横にドラッグし、メニューで**休憩**を選びます。

15分単位で休憩を設定する場合は、メニューの**休憩を追加**から時刻を選びます。

パターン選択と日付選択の募集では、表のセルを押して開くメニューでポジションを選びます。休憩は時間指定の募集だけで設定できます。

## スマートフォンで設定する

1. 日別の表示で、勤務を変えるスタッフのカードを押します。

   <HelpFigure
     src="../images/set-positions-and-breaks/sp-staff-card.webp"
     alt="スマートフォンのシフト表で、スタッフのカードを枠で示した画面"
     width={300}
     height={492}
   />

2. **勤務時間**の行ごとに、ポジションを選びます。
3. 休憩を設定する場合は、**休憩を追加**を押して時刻を選びます。

   <HelpFigure
     src="../images/set-positions-and-breaks/sp-edit-sheet.webp"
     alt="スマートフォンの勤務の編集画面で、勤務時間ごとのポジションと「休憩を追加」を枠で示した画面"
     width={300}
     height={619}
   />

4. 画面の右上にある保存と確定のメニューを開き、**下書きを保存**を選びます。

   <HelpFigure
     src="../images/set-positions-and-breaks/sp-save-menu.webp"
     alt="スマートフォンのシフト表で、右上の保存と確定のメニューと「下書きを保存」を枠で示した画面"
     width={300}
     height={400}
   />
