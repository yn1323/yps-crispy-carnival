シフト作成時、スタッフの配置を一緒に決めることができます。  
ホール、キッチンなどのポジションを指定のある店舗で特に有効な設定です。

利用にはポジション設定が必要となります。  
また、休憩時間も設定可能になります。  （シフト提出方法が時間指定のみ）  

以降の設定はPC・スマホ共通となります。

## ポジションを作る

1. ホームの店舗名の右にある歯車のボタンを押します。

   <HelpFigure
     src="../images/set-positions-and-breaks/home-shop-detail.webp"
     alt="ホームの店舗名の右にある歯車のボタンを押し、店舗詳細画面に遷移します。"
     width={1280}
     height={520}
   />

2. **必要人数設定**を押します。

   <HelpFigure
     src="../images/set-positions-and-breaks/shop-detail-setup.webp"
     alt="店舗の詳細の「シフト作成」にある「必要人数設定」を枠で示した画面"
     width={1280}
     height={760}
   />

3. **ポジションを追加する**からポジションの設定を行います。

   <HelpFigure
     src="../images/set-positions-and-breaks/positions-add.webp"
     alt="ポジションがまだない店舗の必要人数設定で、「ポジションを追加する」を枠で示した画面"
     width={1280}
     height={520}
   />

4. ポジション名、色が設定可能です。

   <HelpFigure
     src="../images/set-positions-and-breaks/position-dialog.webp"
     alt="「ポジションを編集」の画面で、「ポジションを追加」を枠で示した画面"
     width={592}
     height={479}
   />

## シフト表を「くわしく」表示に切り替える

1. 募集中または、要調整状態のシフトを開きます。
2. **表示設定**を押し、**くわしく**を選択すると、ポジションの入力が可能になります。

   <HelpFigure
     src="../images/set-positions-and-breaks/display-settings.webp"
     alt="シフト表の「表示設定」のメニューで、「くわしく」を枠で示した画面"
     width={1280}
     height={340}
   />
