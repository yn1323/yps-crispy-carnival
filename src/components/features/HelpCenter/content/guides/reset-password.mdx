メールアドレスとパスワードでログインしているアカウントのパスワードを再設定します。

## 手順

1. ログイン画面で「パスワードを忘れた方」を押します。
2. 「メールアドレス」を入力し、「再設定コードを送る」を押します。
3. メールに届いた確認コードと新しいパスワードを入力します。
4. 「パスワードを再設定」を押します。

## 完了すると

再設定が完了し、シフトリを利用できる画面へ進めば完了です。

次回からは新しいパスワードを使ってログインします。

## うまくいかない場合

確認コードが届かない場合は、入力したメールアドレスと迷惑メールフォルダを確認してください。

表示されたエラーを修正しても再設定できない場合は、メールアドレスや確認コードを本文へ書かず、画面に表示された文言を添えてお問い合わせください。
