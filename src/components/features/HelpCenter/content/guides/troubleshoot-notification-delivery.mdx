通知履歴、送れなかった通知、スタッフの通知先を順番に確認し、必要な通知を再送します。

## 手順

1. 管理画面のスタッフ一覧から対象スタッフを開き、所属店舗から通知元の店舗を開きます。
2. 店舗別設定の「通知履歴」で、通知の状況と送信方法（メールまたはLINE）を確認します。
3. 「送れませんでした」と表示されている場合は、Dashboardまたはメインナビゲーションの「要対応」を開き、対象の通知を確認します。
4. 個別に送り直す場合は「再送する」を押します。Dashboardで複数件をまとめて送り直す場合は「すべて再送する」を押します。
5. 再送しない通知は「再送せず破棄する」を押し、確認画面でも同じ操作を確定します。
6. 通知が何度も送れない場合は、スタッフ詳細の「スタッフ情報」でシフト通知先メールアドレスを確認し、「LINE連携」で連携状態を確認します。「LINEで受け取れません」と表示されている場合は、スタッフへ再連携を案内してください。

## 完了すると

再送の受付に成功すると、対象のカードが「要対応」から外れます。

この時点は送信処理を受け付けた状態であり、スタッフの端末へ届いたことを確約するものではありません。
必要に応じて、対象店舗の通知履歴をもう一度確認してください。

## うまくいかない場合

操作に失敗した場合は対象のカードが残るため、スタッフの通知先と通知対象の状態を確認してから再試行します。

問い合わせる場合は、スタッフのメールアドレスや外部サービスの詳しいエラー内容を本文へ書かず、画面に表示された状態と通知の種類を添えてください。
