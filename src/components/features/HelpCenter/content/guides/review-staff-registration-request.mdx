スタッフ本人が登録ページから送った参加申請を確認し、承認または却下します。

## 手順

1. ホームの「要対応」で「スタッフ登録申請がN件あります」を開くか、メインナビゲーションの「要対応」を開きます。
2. 申請者名と対象店舗を確認します。
3. スタッフとして追加する場合は「承認する」を押します。
4. 追加しない場合は「却下する」を押し、確認画面で「この申請を却下」を押します。

## 完了すると

承認した場合はスタッフが店舗に追加され、申請が「要対応」から外れます。

却下した場合はスタッフを作成せず、申請が「要対応」から外れます。
却下してもスタッフ本人には通知されないため、必要な場合は担当者から直接案内してください。

## うまくいかない場合

承認時には、申請の状態と利用人数などの上限をもう一度確認します。

利用人数の上限が表示された場合は、「管理」から「組織全体」、「プランと支払い」と進み、現在のプランと利用人数を確認してください。画面の案内に従って上限を解消してから、申請を開き直します。

申請の状態が変わっていて操作できない場合は、画面を再読み込みして「要対応」を確認してください。
