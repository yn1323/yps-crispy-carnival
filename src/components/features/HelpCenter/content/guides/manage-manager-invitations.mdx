組織の「管理者と権限」で、既存スタッフまたは新しいユーザーを管理者として招待できます。

## 操作する前に

招待先のメールアドレスを確認してください。

招待は発行から7日間有効です。管理者枠は、有効な管理者と期限内の招待を合わせて数えます。

| プラン | 管理者枠 |
| --- | ---: |
| Free | 2名 |
| Trial・Standard・Pro | 5名 |

また、管理者はシフトリへのアカウント登録が必要となります。  
詳しい操作手順は管理者招待メールに記載しています。

新しいユーザーを招待する場合は、利用人数の空きも必要です。

## 管理者を招待する

1. アプリの「管理」を開きます。
2. 「組織全体」から「管理者と権限」を開きます。
3. 「既存スタッフを管理者として招待」または「新しいユーザーを管理者として招待」を選びます。
4. 既存スタッフの場合は1名を選び、「管理者として招待する」を押します。
5. 新しいユーザーの場合は「名前」と「メールアドレス」を入力し、「招待する」を押します。
6. 「送信済みの管理者招待」で、宛先、状態、有効期限を確認します。

## 招待メールを再送する・取り消す

1. 「送信済みの管理者招待」から対象者を探します。
2. 新しい案内を送る場合は「再送する」、招待を無効にする場合は「取り消す」を押します。
3. 確認画面で「招待を再送する」または「招待を取り消す」を押します。

再送すると以前の招待URLは使えなくなり、新しい招待URLが発行されます。
取り消すと招待URLは使えなくなり、招待用に確保していた管理者枠が空きます。

## 完了すると

未承認の招待は「送信済みの管理者招待」に表示され、有効な管理者とは別に「招待中」の件数へ数えられます。
招待された人が承認すると、「現在の管理者」に加わります。

## うまくいかない場合

招待ボタンを押せない場合は、画面に表示される理由を確認してください。
有効な管理者と期限内の招待が上限に達している場合は、不要な招待を取り消すか、現在の管理者数を整理してからやり直します。

「送信エラー」と表示された場合は宛先を確認し、正しければ「再送する」を押してください。
宛先が誤っている場合は、その招待を取り消してから正しいメールアドレスで招待し直します。
