スタッフの希望を見ながら勤務を割り当て、確認が終わったシフトを確定します。

## 手順

1. Dashboardまたはシフト一覧から、作成する募集を開きます。
2. スタッフの希望を確認しながら、日ごとの勤務を割り当てます。
3. 作業を途中で止める場合は「下書き保存」を押します。
4. 確定前の警告やエラーが表示された場合は、対象の割り当てを確認して修正します。
5. 内容が決まったら「シフトを確定して通知」を押します。

## 完了すると

募集が確定済みになり、対象スタッフへの確定シフト通知の送信処理が予約されます。

確定操作の完了は、LINEやメールが端末へ届いたことを示すものではありません。

## うまくいかない場合

確定できない場合は、シフト表に表示されたエラーを開き、対象の日付とスタッフを修正してください。

保存や確定の結果を確認できない場合は、同じ操作を繰り返す前に画面を再読み込みし、現在のシフト表の状態を確認します。
