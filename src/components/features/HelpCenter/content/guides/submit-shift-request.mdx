LINEまたはメールに届いた提出リンクから、募集期間中に働ける日や時間を提出します。

## 操作する前に

店舗の設定により、時間を入力する方法、出勤できる日を選ぶ方法、勤務区分を選ぶ方法のいずれかが表示されます。

## 手順

1. シフト募集のお知らせにある提出リンクを開きます。
2. 画面に表示された方法で、希望する日や時間を入力します。
3. 初めて提出する場合は「希望シフトを提出」、提出し直す場合は「希望シフトを更新」を押します。

## 完了すると

「提出が完了しました」と表示されれば、希望シフトは保存されています。

提出期限前に変更する場合は、同じ提出リンクを開いて内容を直し、もう一度提出します。

## うまくいかない場合

リンクが利用できない場合は、画面に表示された募集の状態を確認してください。

提出期限を過ぎており、まだ提出していない場合は確認画面が表示されます。内容を確認し、提出後は同じリンクから変更できないことに同意できる場合だけ「この内容で提出する」を押します。

元の通知を開き直しても提出画面へ進めない場合は、シフト作成担当者へ連絡します。
