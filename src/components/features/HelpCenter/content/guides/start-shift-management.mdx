初回セットアップ後、管理者自身で募集作成から希望提出、シフト表確認までを試してから、スタッフを追加します。

## 手順

1. 初回セットアップの案内に沿って、店舗名と希望シフトの集め方を登録します。
2. Dashboardのシフト一覧で「新しい募集をつくる」を押します。
3. 対象期間、店舗のお休み、提出締切を確認し、「募集をつくる」を押します。
4. 登録したメールアドレスに届いたリンクから、管理者自身の希望シフトを提出します。
5. Dashboardで作成した募集を開き、提出内容がシフト表へ反映されていることを確認します。
6. スタッフ一覧で「スタッフを追加する」を押し、実際に希望シフトを依頼するスタッフを追加します。

## 完了すると

管理者自身の提出内容をシフト表で確認し、スタッフ追加の案内まで進めば、最初の確認は完了です。

## うまくいかない場合

スタッフ追加や募集作成の操作が利用できない場合は、画面に表示された理由と「プランと支払い」の利用状況を確認してください。

案内が次へ進まない場合は、作成した募集への提出と、シフト表を開いて内容を確認する操作まで完了しているか確かめます。
