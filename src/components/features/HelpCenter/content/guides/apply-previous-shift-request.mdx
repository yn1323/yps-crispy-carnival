過去の希望シフトを同じ曜日へ反映し、今回の入力を始めることができます。

## 操作する前に

参照するのは、今回の募集期間より前にあり、月曜日から始まる週のうち、シフトが1件以上ある最新の週です。
直前の暦週にシフトがなければ、さらに前の週が参照される場合があります。

全休みの提出しかない場合、または提出経験がない場合は、前回の内容を適用するボタンは表示されません。

## 手順

1. 今回の希望シフト提出リンクを開きます。
2. 「前回と同じシフトを適用」を押します。日ごとに出勤日を選ぶ募集では「前回と同じ出勤日を適用」と表示されます。
3. 反映された曜日、時間、勤務区分を確認し、今回の希望に合わせて修正します。
4. 初めて提出する場合は「希望シフトを提出」、提出し直す場合は「希望シフトを更新」を押します。

## 完了すると

「提出が完了しました」と表示されれば、今回の希望シフトが保存されています。

「前回と同じシフトを適用」を押しただけでは提出されません。
フォームへ反映した後、必ず提出ボタンを押してください。

## うまくいかない場合

適用ボタンが表示されない場合は、今回の希望を日ごとに入力して提出します。
