メインナビゲーションの「要対応」では、管理者の判断や操作が必要な項目を種類ごとに確認できます。

## 表示される項目

| 種類 | 表示される状態 | 主な操作 |
|---|---|---|
| シフト | 提出締切を過ぎても募集中のシフト | 「シフトを組む」でシフト表を開く |
| スタッフ | 承認待ちのスタッフ登録申請 | 承認、または確認後に却下 |
| 通知 | 未解決の送れなかった通知 | 再送、または「再送せず破棄する」で対応済みにする |
| 管理 | 送信エラー、管理者数の上限超過、競合がある管理者招待 | 再送、または確認後に取り消す |

送信済みの通知、承認・却下済みの申請、解決済みの通知、通常の招待中は「要対応」へ表示されません。

## 手順

1. メインナビゲーションから「要対応」を開きます。
2. 特定の店舗だけを確認する場合は、画面上部の対象店舗を切り替えます。
3. 各カードの内容を確認し、必要な操作を選びます。
4. 却下、通知の破棄、招待の取り消しは、確認画面の内容を読んでから確定します。

## 完了すると

操作が完了した項目は一覧から外れます。
通知の再送などが再び失敗し、対応が必要な状態へ戻った場合は同じ項目が再表示されます。

## うまくいかない場合

閲覧のみの管理者は内容を確認できますが、承認、再送、取り消しはできません。

一覧を読み込めない場合は「再読み込み」を押します。
操作に失敗した場合はカードや確認画面が残るため、表示された案内を確認して再試行してください。
