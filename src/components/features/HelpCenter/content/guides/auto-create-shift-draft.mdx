時間別の必要人数を設定することで、スタッフの希望をもとにシフトを自動で作成します。  
スタッフ人数の多い店舗で有効です。

/>


## 必要人数とスキルを設定する

自動作成にあたり、事前に時間帯別の必要人数設定が必要です。  

必要人数はポジションごとに設定します。  
ポジションがない店舗の場合、適当なポジションを1つ作成したください。  
ポジションの作り方は[ポジションと休憩時間を設定する](/help/set-positions-and-breaks)を確認ください。

1. ホームの店舗名の右にある歯車のボタンを押します。

   <HelpFigure
     src="../images/auto-create-shift-draft/home-shop-detail.webp"
     alt="シフトリホームで、店舗名の右にある店舗詳細のボタンを枠で示した画面"
     width={1280}
     height={520}
   />

2. **必要人数設定**を押します。

   <HelpFigure
     src="../images/auto-create-shift-draft/shop-detail-setup.webp"
     alt="店舗の詳細の「シフト作成」にある「必要人数設定」を枠で示した画面"
     width={1280}
     height={760}
   />

3. 曜日ごとの必要人数テンプレートを設定します。  
テンプレート分けるの例）月〜木は2名体制、金曜のみ4名体制、年末年始は10名体制...など

   <HelpFigure
     src="../images/auto-create-shift-draft/templates.webp"
     alt="必要人数設定の「必要人数」で、テンプレートの一覧とテンプレート利用日を枠で示した画面"
     width={1280}
     height={433}
   />

4. 時間帯のポジションごとに必要人数を入力します。（PC&スマホ共通）

   <HelpVideo
     src="../videos/auto-create-shift-draft/staffing-band.mp4"
     title="帯をドラッグして必要人数を設定する"
     width={1920}
     height={1080}
   />

5. 【任意設定】「スタッフのスキル」を設定するとスキルを考慮してシフトを作成します。  
例1）Aさん ポジション「キッチン」を**担当外**に設定した場合、自動作成でAさんのポジションに「キッチン」が割り当たらなくなります。  
例2）Bさん ポジション「ホール」を**見習い**に設定した場合、ホール担当がBさん1名になる時間帯があると警告を表示します。  
（一人前は特になにもありません）

   <HelpFigure
     src="../images/auto-create-shift-draft/staff-skills.webp"
     alt="必要人数設定の「スタッフのスキル」で、スタッフとポジションのマスを枠で示した画面"
     width={650}
     height={458}
   />

## シフトを自動作成する

1. シフト表を開き、**表示設定**で**くわしく**を選びます。

   <HelpFigure
     src="../images/auto-create-shift-draft/display-settings.webp"
     alt="シフト表の「表示設定」のメニューで、「くわしく」を枠で示した画面"
     width={1280}
     height={340}
   />

2. 画面の右上にある**自動作成**を押します。

   <HelpFigure
     src="../images/auto-create-shift-draft/board-auto-create.webp"
     alt="シフト表の右上にある「自動作成」を枠で示した画面"
     width={1280}
     height={300}
   />

   スマートフォンでは、保存・確定 → **シフトを自動作成**を選びます。

   <HelpFigure
     src="../images/auto-create-shift-draft/sp-auto-create-menu.webp"
     alt="スマートフォンのシフト表で、右上の保存と確定のメニューと「シフトを自動作成」を枠で示した画面"
     width={300}
     height={400}
   />
