組織の「プランと支払い」で、現在のプラン、利用数、支払いに関する状態を確認します。

## 操作する前に

複数の組織に所属している場合は、確認する組織へ切り替えてから操作します。

## 手順

1. アプリの「管理」を開きます。
2. 「組織全体」から「プランと支払い」を開きます。
3. 「現在のプラン」と支払いに関する案内を確認します。
4. 「利用人数」「店舗数」「管理者数」で、現在の件数と上限を確認します。
