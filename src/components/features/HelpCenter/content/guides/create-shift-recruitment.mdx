シフト期間と提出期限を指定して、スタッフから希望シフトを集める募集を作成します。

## 手順

1. Dashboardまたはシフト一覧で「新しい募集をつくる」を押します。
2. 複数店舗のシフト一覧から開いた場合は、募集を作成する店舗を選びます。
3. シフト期間を入力し、店舗のお休みを確認します。
4. 希望シフトの提出期限を入力します。
5. 確認画面で店舗、期間、提出期限を確かめ、「募集をつくる」を押します。

## 完了すると

募集が「募集中」に表示され、対象スタッフへの提出依頼と、条件を満たす催促の送信処理が予約されます。

画面上の完了は、LINEやメールが端末へ届いたことを示すものではありません。

## うまくいかない場合

作成操作が利用できない場合は、画面に表示された店舗の状態、管理権限、組織の利用状態に関する案内を確認してください。

シフト期間や提出期限の入力エラーが表示された場合は、その項目を修正してから確認画面へ進みます。
