シフト期間と提出期限を指定して、スタッフから希望シフトを集める募集を作成します。

## 手順

1. シフトリホームまたはシフト一覧で「新しい募集をつくる」を押します。
2. 複数店舗のシフト一覧から開いた場合は、募集を作成する店舗を選びます。
3. シフト期間を入力し、店舗のお休みを確認します。
4. 希望シフトの提出期限を入力します。
5. 確認画面で店舗、期間、提出期限を確かめ、「募集をつくる」を押します。

## 完了すると

対象スタッフへの提出依頼通知を自動的に送信します。
