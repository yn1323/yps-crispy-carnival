店舗詳細から、店舗名、希望シフトの集め方、勤務時間、定休日をまとめて変更します。

## 操作する前に

この手順は、店舗詳細に「編集する」が表示され、操作できる管理者向けです。

## 手順

1. Dashboardで現在の店舗の詳細を開きます。
2. 基本情報の「編集する」を押します。
3. 「店舗設定」で変更する内容を入力し、画面の案内に沿って「次へ」を押します。
4. 最後の「定休日」まで進み、内容を確かめて「変更を保存」を押します。

## 完了すると

「店舗設定を更新しました」と表示され、店舗詳細の基本情報が新しい内容になれば完了です。

希望シフトの集め方は、変更後に作成する募集から使われます。

## うまくいかない場合

「編集する」が利用できない場合は、店舗詳細に表示された閲覧専用または利用状態の案内を確認してください。

保存中に店舗の状態が変わった場合は、最新の店舗詳細を読み込んでから入力し直します。
