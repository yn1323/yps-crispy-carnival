対象期間ごとに、募集、提出確認、割り当て、確定の順でシフト管理を進めます。

## 運用チェックリスト

1. **募集する**：[シフト募集を作成する](/help/create-shift-recruitment)を参考に、店舗、シフト期間、提出締切を指定します。
2. **提出を確認する**：Dashboardまたはシフト一覧で提出人数を確認し、必要に応じてスタッフへ[希望シフトを提出する](/help/submit-shift-request)手順を案内します。
3. **割り当てを作る**：[シフトを作成して確定する](/help/build-and-confirm-shift)を開き、スタッフの希望を見ながら勤務を割り当てます。作業を中断する場合は「下書き保存」を押します。
4. **確定する**：エラーを修正し、確認事項を確かめてから「シフトを確定して通知」を押します。
5. **必要な変更を反映する**：確定後に割り当てを変える場合は、[確定済みシフトを変更して再通知する](/help/update-confirmed-shift)手順で保存と再通知を行います。

## 完了すると

対象期間の募集が確定済みになり、確定シフト通知の送信処理が予約されます。

次の期間を管理するときは、新しい対象期間を指定して同じチェックリストを進めます。

## うまく進まない場合

希望が全員分そろっていなくても、割り当てを始めて下書き保存できます。

募集作成、保存、確定の操作が利用できない場合は、画面に表示された店舗の状態、管理権限、組織の利用状態に関する案内を確認してください。
