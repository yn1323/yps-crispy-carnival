店舗詳細から、店舗名、希望シフトの集め方、勤務時間、定休日をまとめて変更します。

## 手順

1. シフトリホームで現在の店舗の詳細を開きます。
2. 基本情報の「編集する」を押します。
3. 「店舗設定」で変更する内容を入力し、画面の案内に沿って「次へ」を押します。
4. 最後の「定休日」まで進み、内容を確かめて「変更を保存」を押します。
