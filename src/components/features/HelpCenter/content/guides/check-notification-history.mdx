スタッフの店舗別設定から、メールまたはLINEで送った通知の日時、目的、状況を確認します。

## 手順

1. 管理画面のスタッフ一覧から、確認するスタッフを開きます。
2. 店舗別設定から、通知を確認する店舗を開きます。
3. 「通知」セクションの通知履歴を確認します。
4. 続きがある場合は「もっと見る」を押します。

## 完了すると

通知を依頼した日時、使用したチャネル、通知の目的、送信または配信の状況を確認できます。

- **送信待ち**：シフトリで送信処理を受け付け、送信を待っている状態です。
- **送信済み**：外部サービスが送信要求を受け付けた状態です。スタッフの端末への到達は確約できません。
- **配信済み**：外部サービスから配信完了が報告された状態です。スタッフ本人の開封や既読を示すものではありません。
- **配信が遅れています／送れませんでした／キャンセル**：通知がまだ完了していない、失敗した、または送信対象から外れた状態です。必要に応じて「要対応」を確認し、再送してください。

シフトリでは、スタッフ本人の開封や既読は確認できません。

## うまくいかない場合

古い通知が表示されない場合があります。

通知履歴は、この機能の提供開始後に新しく送信処理へ登録されたスタッフ向け通知を対象にしています。

履歴を読み込めない場合は、画面を再読み込みし、対象の組織と店舗を開いているか確認してください。
