LINEまたはメールに届いた元の提出リンクを開き直してください。  

それでも「このリンクでは提出できません」と表示される場合は、シフト作成担当者へ連絡してください。  

また、募集が削除済み、確定済み、またはシフト開始日を迎えている場合は、提出できません。  

提出期限超過〜確定までの間であれば、シフトが提出可能です。  

すでに提出している場合は、提出内容の確認のみ可能です。
