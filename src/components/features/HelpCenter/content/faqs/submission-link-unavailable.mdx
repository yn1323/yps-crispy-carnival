LINEまたはメールに届いた元の提出リンクを開き直してください。

それでも「このリンクでは提出できません」と表示される場合は、シフト作成担当者へ連絡してください。

募集が削除済み、確定済み、またはシフト開始日を迎えている場合は、提出受付が終了しています。

提出期限を過ぎただけでは受付終了になりません。

募集が確定前かつシフト開始日前で、まだ提出していない場合は、確認画面を経て初回提出できます。

すでに提出している場合は、提出内容の確認だけできます。
