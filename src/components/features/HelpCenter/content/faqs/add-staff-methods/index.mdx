スタッフ本人から参加申請を送ってもらう方法と、管理者が情報を入力して追加する方法があります。

同じ組織の別店舗に登録済みのスタッフは、候補として表示される場合に対象店舗へ追加できます。

本人からの参加申請は、管理者が承認するとスタッフ一覧へ追加されます。
