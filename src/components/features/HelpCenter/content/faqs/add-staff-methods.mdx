シフトリのホーム・スタッフ一覧から追加可能です。  

新しいスタッフを登録する方法は3通りあります。

- 専用ページからスタッフ自身に入力してもらう（※）
- 管理者がスタッフ情報を入力する
- 組織から探して追加する

※スタッフ自身が入力した場合は、「要対応」ページで管理者が承認すると追加されます。

同じ組織に登録済みで、追加先の店舗に所属していないスタッフは、「組織から探して追加する」から追加できます。
別店舗に所属しているスタッフと、所属店舗のないスタッフが対象です。
