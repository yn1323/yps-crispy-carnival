シフトリのホーム・スタッフ一覧から追加可能です。  

2通りの登録方法があります。

- 専用ページからスタッフ自身に入力してもらう(※)
- 管理者がスタッフ情報を入力する

※スタッフ自身が入力した場合、要対応ページから管理者の承認を持って追加となります。
