# 無料のシフト管理アプリの選び方

「シフト管理 無料」で検索すると、たくさんのアプリが見つかります。  
ところが開いてみると、自分のバイト予定を記録する個人向けアプリだったり、無料なのは最初の数か月だけだったりします。

同じ「無料」でも、誰のためのツールか、どこまで無料かはそろっていません。  
店長が比べるべきなのは機能の多さより、自店の人数と運用で、無料の範囲に収まるかどうかです。

---

## 無料のツールに混ざる3つのタイプ

| タイプ | 例 | 向いている人 |
| --- | --- | --- |
| 個人向けアプリ | バイトの予定表、給料計算アプリ | 自分の勤務予定を記録したいスタッフ |
| 汎用ツールの流用 | フォームと表計算、LINEグループ | 費用をかけずに始めたい店 |
| 店舗向けサービス | 無料体験、無料プラン | 希望回収から共有までまとめたい店 |

個人向けアプリは、スタッフ全員のシフトを管理する用途には向きません。  
「複数人のシフトを1か所で管理できるか」が、最初に見分ける点です。

汎用ツールは、希望を集めるところまでは十分に使えます。  
ただし、回答をシフト表の形へ組み替える作業と、未提出者の確認、確定後の共有は手作業で残ります。

---

## 店舗で使う前に確かめる5つの条件

1. **スタッフの負担**：アプリのインストールやアカウント登録が要るか。リンクを開くだけで提出できれば、導入の案内が短く済む
2. **無料の範囲**：人数、店舗数、管理者数の上限と、無料で使える期間
3. **流れのつながり**：希望回収、未提出の確認、作成、確定の共有が一続きになっているか
4. **催促の手間**：未提出者が一覧で分かるか、自動のリマインドがあるか
5. **有料になる条件**：無料期間が終わったときや上限を超えたときに、何が起きるか

とくに2と5は、自店の数字を当てはめて確かめます。  
スタッフ8人と店長1人の店なら、「5名まで無料」のプランには収まりません。  
無料体験のあとに有料契約が要るのか、そのときにデータがどう扱われるのかまで確認しておくと、途中で運用を戻す事態を避けられます。

## シフトリの無料の範囲

[シフトリ](https://shiftori.app)は、店舗向けのシフト管理サービスです。  
初回登録から2か月は、クレジットカードを登録せずに無料で試せます。  
無料体験中は、Proと同じ機能を、利用人数50名、店舗5件、管理者5名まで使えます。

無料体験の終了後に有料プランを選ばない場合は、Freeプランへ自動で移ります。  
Freeプランでは、利用人数5名（管理者を含む）、1店舗、管理者2名まで、基本機能を無料で使い続けられます。  
上限を超える場合は、StandardかProを選びます。

- スタッフは、LINEやメールで届いたリンクから希望を提出できる
- 提出状況を一覧で確認でき、締切前日17時より前に募集を作ると、未提出者への自動リマインドが予約される
- 確定したシフトは、LINEまたはメールでスタッフに届く

登録なしで操作できるデモもあるため、画面を見てから試すかを決められます。

---

## 次の募集1回分で比べる

候補が決まったら、次のシフト募集1回分だけ使ってみてください。  
希望の転記、未提出者への催促、確定表の送り直しにかかった時間を、いまの方法と比べれば、無料の範囲で続けられるかを判断できます。
