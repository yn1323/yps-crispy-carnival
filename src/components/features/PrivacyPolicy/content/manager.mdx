シフト管理SaaS「シフトリ」は、個人情報の保護を重視しています。  
本ポリシーは、管理ユーザーの方が店舗管理やスタッフ管理を行う際に、本サービスが取り扱う情報について説明するものです。

## 1. 取得する情報

### 管理ユーザーに関する情報

- 氏名、メールアドレス、認証に必要な情報
- 組織名、店舗名、営業時間などの組織・店舗情報
- 登録したスタッフ情報、シフト募集・確定に関する情報
- 請求先メールアドレス、契約プラン、無料体験期間、利用人数・店舗数・管理者数
- Stripeの顧客・契約・請求を識別する情報、支払い状態、請求履歴
- サービス上で送信した要望、問い合わせ内容
- 利用規約・プライバシーポリシーへの同意日時と同意バージョン

カード番号、セキュリティコードなどの支払い方法の詳細はStripeが取得し、本サービスでは保存しません。

## 2. 利用目的

- アカウント認証と組織・店舗管理機能を提供するため
- スタッフ登録、シフト募集、シフト作成、通知送信を行うため
- 無料体験、契約プラン、利用上限、支払い、請求、契約状態を管理するため
- 不正な契約操作や利用上限の回避を防止し、支払いに関する問い合わせへ対応するため
- サービスの保守、改善、問い合わせ対応のため
- 利用規約・プライバシーポリシーへの同意状態を確認するため

## 3. 外部サービス

本サービスでは、認証、データ保存、決済・請求、メール送信、LINE通知、アクセス解析のために、外部サービスを利用する場合があります。

外部サービスで取り扱われる情報は、本サービスの提供に必要な範囲に限ります。

- Clerk: 認証基盤
- Convex: データベース、アプリケーション基盤
- Cloudflare: Webサイトの配信、不正な自動送信の防止
- Stripe: 決済、契約、請求、支払い方法の管理
- Resend: メール配信
- LINEヤフー: LINE連携、LINE通知
- Google Analytics: 同意を得た場合のアクセス解析、サービス改善
- Slack: 問い合わせの社内共有

## 4. 情報の保持と削除

契約・請求に関する情報は、サービス提供、法令上の義務、請求に関する問い合わせ、不正利用の防止に必要な期間保持します。

利用目的に照らして不要となった情報は、法令または契約上保持が必要な情報を除き、削除または個人を識別しにくい形へ変更します。

## 5. 第三者提供

運営者は、法令に基づく場合を除き、本人の同意なく個人情報を第三者に提供しません。  
外部サービスの利用は、第三者提供ではなく、本サービスの運営に必要な業務委託として行います。

## 6. 問い合わせ

個人情報の取り扱いに関する問い合わせは、サービス上のお問い合わせフォームからご連絡ください。

関連する利用条件は、[管理ユーザー向け利用規約](/terms/manager)をご確認ください。
