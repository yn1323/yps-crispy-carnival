シフトリでは、次の順にシフトを作成します。

1. ダッシュボード上部の「編集」から、希望シフトの集め方と店舗のお休みを設定します。
2. 「スタッフ一覧」の「スタッフを招待」から、シフトを提出するスタッフを追加します。
3. 「シフト一覧」の「新しい募集をつくる」から、シフト期間と提出締切を決めます。
4. スタッフがLINEまたはメールで届いたリンクから希望シフトを提出します。
5. ダッシュボードで提出状況を確認し、集まった希望を見ながらシフト表を調整します。
6. 「シフトを確定して通知」を押し、確定シフトをスタッフへ送ります。

作成途中のシフト表は下書きとして保存できます。

スタッフから希望が届く前でも作成を始められますが、未提出のスタッフはシフト表で区別して表示されます。
