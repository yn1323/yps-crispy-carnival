提出締切の前日17:00に、希望シフトをまだ提出していないスタッフへ催促を自動で送ります。

LINE連携済みで友だち追加中のスタッフにはLINE、それ以外のスタッフにはメールで送ります。

シフト対象外に設定したスタッフには送りません。

<HelpNote>締切前日17:00を過ぎてから募集を作成した場合、自動催促は予約されません。</HelpNote>
