スタッフは、LINEまたはメールで届いた提出リンクから希望シフトを提出します。

専用アプリのインストールや、シフトリへのログインは必要ありません。

1. 届いた提出リンクを開きます。
2. 日付、時間、勤務区分など、店舗が設定した方法で希望を入力します。
3. 内容を確認して「提出する」を押します。
4. 締切前に変更したい場合は、同じリンクを開いて提出し直します。
5. シフト確定後は、LINEまたはメールで届いた閲覧リンクから自分のシフトを確認します。

リンクを開けない場合は、画面に表示された案内に従うか、シフト作成担当者へ連絡してください。
