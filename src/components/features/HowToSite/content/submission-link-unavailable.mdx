提出リンクを開いたときは、画面に表示された案内を確認してください。

「このリンクでは提出できません」と表示された場合は、新しい案内が必要かシフト作成担当者へ確認してください。

募集が削除されている場合は、その募集には提出できません。

提出受付が終了している場合は、変更したい内容をシフト作成担当者へ連絡してください。

リンクの文字列をほかのスタッフへ転送しても、そのスタッフの提出には使えません。
