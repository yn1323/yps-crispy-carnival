3つの違いは、スタッフが希望シフトを提出するときの入力のしかたです。

- **時間指定**：働ける開始時間と終了時間を、日ごとに入力します。
- **日ごと**：出勤できる日だけを選びます。
- **勤務区分**：早番や遅番など、店舗が用意した勤務区分から選びます。同じ日に複数選べます。

提出方法は、ダッシュボードの店舗名の横にある「店舗詳細」を開き、基本情報の「編集する」を押して「希望シフトの集め方」で選びます。  
選んだ提出方法は、次に作成するシフト募集から反映されます。
