ダッシュボード上部の「編集」を押し、「希望シフトの集め方」で提出方法を選びます。

選んだ方法によって、スタッフの提出のしかたが変わります。

- **時間指定**：働ける開始時間と終了時間を日ごとに入力します。
- **日ごと**：出勤できる日だけを選びます。
- **勤務区分**：早番や遅番など、店舗が用意した勤務区分から選びます。

勤務区分は、同じ日に複数選べます。

選んだ提出方法は、次に作成するシフト募集から反映されます。
