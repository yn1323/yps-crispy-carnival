提出締切前であれば、スタッフは最初に届いた提出リンクから希望シフトを変更できます。

リンクを開くと、現在の提出内容が入力された状態で表示されます。

内容を直してもう一度提出すると、以前の希望は新しい内容に置き換わります。

提出締切を過ぎたあとは、提出済みの内容を確認できますが、変更はできません。
