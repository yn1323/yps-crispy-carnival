提出方法の変更は、変更後に作成するシフト募集から反映されます。

すでに作成した募集は、作成したときの提出方法のままです。

募集中のシフトを別の提出方法へ切り替えることはできません。

作り直す場合は、先に募集を削除するとどうなるかを確認してください。
