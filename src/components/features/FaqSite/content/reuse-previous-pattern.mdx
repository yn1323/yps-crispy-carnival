過去に勤務希望を提出している場合は、「前回と同じシフトを適用」から、直近のシフトがある週の曜日と時間を今回の期間へ反映できます。

反映後も自動では提出されません。日付ごとの内容を確認し、「提出する」を押してください。  
提出履歴がない場合や、前回がすべて休みだった場合は表示されません。
