組織設定の「管理者を追加」から、組織内の既存スタッフまたは新しいユーザーへ管理者招待を送ります。
招待はメールで届き、受取人がログインまたはアカウント登録後に承認すると管理者になります。

有効な管理者は、組織内のすべての店舗、利用者、プラン・支払いを管理します。
店舗だけに限定した管理者権限はありません。

送信済みの招待は、管理者設定で再送または取り消しできます。
管理者数と利用人数がプラン上限に達している場合は、新しい招待を送れません。

Freeプランでは、招待中を含めて管理者を2名まで登録できます。
管理者を交代する場合は、後任が招待を承認してから、前任者の管理者権限を外してください。
最後の有効な管理者の権限は外せません。

以前の方式で送信した管理者交代招待が残っている場合は、その招待を取り消すか、有効期限が切れてから新しい管理者を追加してください。
