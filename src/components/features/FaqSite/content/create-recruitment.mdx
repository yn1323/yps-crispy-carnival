シフト対象のスタッフへ、希望シフトの提出リンクが届きます。  
LINE連携済みのスタッフには通常LINEで届き、LINEを利用できない場合やLINE送信の上限に達した場合はメールへ切り替わります。

締切前日の17:00をまだ過ぎていない場合は、未提出スタッフへの自動催促も予約されます。
