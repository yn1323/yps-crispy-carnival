始められます。  
未提出のスタッフはシフト表で区別して表示され、管理者が勤務を割り当てることもできます。

提出前のスタッフへ勤務を入れると確認事項が表示されます。  
あとから希望が届いたら、割り当てと希望を見比べて調整してください。
