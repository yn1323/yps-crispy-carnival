組織内のスタッフと管理者を、人物単位で数えます。
管理者本人をスタッフとして登録していても1名です。

シフト対象外のスタッフも利用人数に含まれます。
店舗から外しただけでは組織の利用者として残るため、利用人数を減らす場合は組織からの削除が必要です。

初回登録で適用されるBusinessの利用人数上限は40名です。
