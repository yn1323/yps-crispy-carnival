原則として、前回の確定通知から割り当てが変わったスタッフだけに届きます。  
割り当てが変わっていないスタッフには届きません。

通知対象の記録がない古い確定済みシフトは、機能導入後の初回再通知に限り全員が対象になる場合があります。  
最終的な対象は「もう一度通知」の確認画面で確認してください。
