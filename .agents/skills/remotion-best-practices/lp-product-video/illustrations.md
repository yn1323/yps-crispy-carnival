# イラストをCodexで作る

動画内のイラストは、Codex CLI（gpt-6-sol）の画像生成で作る。  
実写は使わず、1本の動画の中ではすべて同じタッチにそろえる。

## 手順

1. タッチの基準にする画像を決める。
2. 最初に登場人物の設定画を1枚作る。全員を横一列に、上半身・正面・背景透明で描かせる。以降の絵は、基準画像と設定画の両方を参照させる。
3. 絵コンテから必要な絵を洗い出す。顔アイコンは設定画から切り出し、個別には生成しない。
4. 下の「共通の指示文」に、絵ごとの「描く内容」と「出力」を足して、1枚ずつ指示する。互いに依存しない絵は並行して生成してよい。
5. 生成後に「確認」を行い、崩れた絵だけを作り直す。

## Codexの呼び出し方

```bash
codex exec -m gpt-6-sol -C <リポジトリ> -s workspace-write \
  -i <タッチの基準画像> -i <設定画> \
  -o <結果の記録先>.txt - < <指示文>.md
```

- 先に`codex features list`で`image_generation`が有効か確認する。
- 指示文は標準入力で渡す。
- 参照画像は`-i`で添付したうえで、指示文でも絶対パスを示し、画像生成ツールの参照画像として渡すよう書く。
- 並行して動かすときは、ジョブごとに指示文と結果の記録先を分ける。
- `-s workspace-write`で動かすため、指示文で仕事の範囲を必ず限定する。

## 指示文のコツ

- 冒頭で仕事を「画像を1枚生成して、指定のパスへ保存することだけ」に限定し、他のファイルの作成・変更・削除とコードの記述を禁じる。
- 用途（どの動画のどこで使うか）と、同じタッチで何枚も作ることを書く。
- 画風は参照画像に任せきりにせず、言葉でも固定する。主線、塗り、アクセント色、背景の形、顔の描き方、余白を具体的に書く。
- 背景は透明を指定し、できない場合だけ純白の無地を許す。
- 入れないものを明記する。文字、数字、ロゴ、看板の文字、写実、光沢のある3D、濃いグラデーション、ストックイラスト風。日本語の文字は崩れやすいので、文字は動画側で重ねる。
- 人物は設定画での名前と特徴（年代、髪型、服装）で指定し、顔立ち・髪型・服装・線の太さ・塗りの色を設定画と一致させるよう書く。
- 1枚には1つの動作だけを描かせ、状況は表情と小物で伝える。例は、困り眉と汗、OKサイン、両手で持ったコーヒー。
- サイズを指定する。人物や小物は正方形（1024×1024）、店の外観や横並びの絵は横長（1536×1024）にする。
- 小物を何種類か並べる場合は「横一列に等間隔、重ならない、同じ大きさ」と書き、動画側で切り出す。
- 最後に「保存したパスと、背景が透明か白か」を1行で報告させる。

## 確認

- `git status`で、指示した保存先以外のファイルが変わっていないことを確認する。
- `sips -g hasAlpha <ファイル>`で、背景が透明かを確認する。
- 絵が描かれている範囲を測る（`magick <ファイル> -alpha extract -threshold 20% -format '%@' info:`）。キャンバスの中で小さく描かれることがあるため、動画側の切り出し位置と拡大率はこの値から決める。
- すべての絵を白い背景に並べた一覧画像を作り、タッチ、人物の顔立ち、色がそろっているかを見比べる。
- 作り直すときは、共通の指示文を変えずに「描く内容」だけを直す。

## 共通の指示文

`<…>`の部分を置き換え、この後ろに「描く内容」と「出力」を足す。  
画像生成ツールに渡すパスは絶対パスにする。

```markdown
あなたの仕事は、画像生成ツールでイラストを1枚生成し、指定のパスへ保存することだけです。
リポジトリ内の他のファイルは作成・変更・削除しないでください。コードも書かないでください。

## 用途
<サービス名>のLP用紹介動画（音なし、16:9）で使う素材です。動画内のイラストはすべて同じタッチにそろえます。

## 参照画像（画像生成ツールに参照画像として必ず渡すこと）
- タッチの基準: <基準画像の絶対パス>
- 登場人物の基準: <設定画の絶対パス>
  - 左から、<人物ごとの名前と特徴>
  - 人物を描く場合は、顔立ち・髪型・服装・線の太さ・塗りの色を設定画と一致させること

## 画風
- 手描き風の黒い主線（わずかに揺らぎのある線）、フラットな塗り
- 色は<アクセント色>をアクセントに、淡い<背景形の色>の丸い背景形、それ以外はグレースケール
- シンプルな顔、丸みのある形、親しみやすい表情、余白の多い構図
- 背景は透明（透明にできない場合のみ純白 #FFFFFF の無地）
- 写実表現、光沢のある3D、濃いグラデーション、ストックイラスト風、文字、数字、ロゴ、看板の文字は入れない
```

絵ごとに足す部分の例は次のとおり。

```markdown
## 描く内容
店長が、片手でスマートフォンを見ながら困っている上半身（腰から上）。困り眉、小さな汗のしずく。スマートフォンの周りに、文字のない小さな吹き出しが3つ浮かぶ。正方形（1024x1024）。

## 出力
- 生成した画像を <保存先の絶対パス> として保存する
- 最後に、保存したパスと、背景が透明か白かを1行で報告する
```

## シフトリで作る場合

- タッチの基準画像は`doc/assets/article-hero-style-reference.png`、設定画は`apps/video/public/illustrations/character-sheet.png`、保存先は`apps/video/public/illustrations/`にする。
- 登場人物は、左から店長（30代後半の男性、短い黒髪、白い襟付きシャツ）、高橋さき（大学生の女性、ポニーテール）、山本はると（大学生の男性、ティールのキャップ）、小林みお（30代の女性、お団子）、中村ゆい（20代の女性、ボブ）。全員ティールのエプロンを着る。
- アクセント色はティール（深い青緑）、背景形は淡いミントにする。
- 顔アイコンの切り出し位置は`apps/video/src/ShiftoriIntro/components/People.tsx`の`CROPS`にある。
- 既存のイラストと用途は、`doc/plans/2026-09-25_LP紹介動画_絵コンテ.md`の「素材」にある。
