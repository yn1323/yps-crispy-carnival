# シフト作成の設定

> 文書種別: feature
>
> 最終コード照合: 2026-11-16

店舗が、シフトを組むときに使うポジション、必要人数、休憩の決まり、スタッフの属性を設定する機能である。  
設定した内容は、[シフト表](shift-board.md)の「くわしく」表示で使う。  
何も設定しない店舗は、従来のシフト表をそのまま使える。

## 保証する範囲

設定の保存、店舗をまたいだ参照の拒否、上限の検証を扱う。  
労務の基準は示さない。  休憩の長さや必要人数は、店舗が決めた数字をそのまま持つ。

## 画面

| 画面 | 利用者ができること |
|---|---|
| `/manage/shops/<shopId>/shift-setup?org=<organizationId>` | 店舗のポジション、必要人数、休憩の決まり、スタッフの属性を設定する |

店舗詳細の「シフト作成」と、シフト表の「くわしく」表示にある「シフト作成の設定」から開く。  
URLの`org`と`shopId`の一致は、QueryとMutationの双方で確かめる。  
契約状態によって書き込めない組織では、設定を閲覧だけできる。

## 設定できる内容

### ポジション

ホールやキッチンなど、勤務の役割を表す。  
名前、色、並び順を変えられ、有効なポジションは10件まで持てる。  
色は用意した10色から選ぶ。

店舗を作ったときにできる最初のポジションは削除できない。  名前と色は変えられる。  
削除したポジションを指す勤務は、シフト表と確定通知で最初のポジションとして扱う。

### 必要人数

1日分の「区切り」と、区切りごと・ポジションごとの必要人数を「型」として持つ。  
型は6件まで作れ、曜日に割り当てる。  同じ曜日を2つの型に割り当てることはできない。

区切りの形は、店舗の希望シフトの集め方で決まる。

| 集め方 | 区切り |
|---|---|
| 時間指定 | 時間帯。開始と終了を選び、8件まで持てる |
| パターン選択 | 勤務パターン。店舗設定の勤務パターンがそのまま並ぶ |
| 日付選択 | 1日 |

人数は表の各マスを−と＋で増減する。  0人は未設定と同じ意味で、保存しない。  
集め方を変えた店舗では、合わなくなった区切りを表示せず、次の保存で消す。

特別な日は、シフト表でその日に別の型を当てる。  設定ページでは扱わない。  
型を削除すると、その型を当てていた日は曜日の割り当てへ戻る。

### 休憩の決まり

「何分以上の勤務に何分の休憩」を1つ持つ。  
決まりがある店舗では、シフト表の「くわしく」表示で新しく作った勤務と、希望から作った勤務の候補に、決まりの長さの休憩が初期値として入る。  
日付選択の勤務には長さがないため、初期値は入らない。

### スタッフ

シフト対象のスタッフごとに、入れないポジションと熟練度（新人、標準、責任者）を持つ。  
初期値は、全ポジションに入れて熟練度が標準である。  入れるポジションは1つ以上残す。  
ポジションの削除で、残ったポジションのすべてが「入れない」になったスタッフは、全ポジションに入れるものとして扱う。  
熟練度は管理者の画面だけに表示し、スタッフ向けの画面と出力には出さない。

## AIサポート

店の状況を文章で入力すると、型の下書きが編集中の表に入る。  
下書きは保存されず、管理者が内容を確かめて保存したときに設定になる。

現在は実際のAIにつないでいない。  入力した文章は読まず、区切りを店舗の集め方から作り、必要人数をランダムな値で埋める。  
文章は保存せず、ログにも出さない。

Convexの環境変数`SHIFT_SETUP_ASSIST_MODE`が`random`の環境だけで使える。  
未設定の環境では画面に出ず、actionを直接呼んでも下書きを返さない。  
根拠のない人数を店舗へ見せないため、Productionでは設定しない。

## 保存のしかた

ポジション、型、スタッフの属性は、画面の一覧をまとめて保存する。  
型とスタッフの属性は、変更があるときだけ画面の下端に出る操作から保存する。  
保存していない変更がある状態でページを離れようとすると、確認を表示する。

## Public API

| API | 用途 |
|---|---|
| `api.shiftSetup.queries.getShiftSetup` | 店舗の設定、シフト対象スタッフの属性、AIサポートを使えるかを返す |
| `api.shiftSetup.mutations.savePositions` | ポジションの一覧を置き換える。一覧にない既存のポジションは論理削除する |
| `api.shiftSetup.mutations.saveDayTemplates` | 型の一覧を置き換える。既存の型はIDを引き継ぐ |
| `api.shiftSetup.mutations.saveBreakRule` | 休憩の決まりを保存する。`null`で決まりをなくす |
| `api.shiftSetup.mutations.saveStaffShiftProfiles` | スタッフの入れないポジションと熟練度をまとめて保存する |
| `api.shiftSetup.mutations.setDayTemplateOverride` | 特別な日に当てる型を変える。`null`で曜日の割り当てへ戻す |
| `api.shiftSetup.actions.suggestShiftSetup` | 型の下書きを返す。設定は保存しない |

どのAPIも、対象店舗が属する組織の有効な管理者だけが使える。  
受け取ったポジション、スタッフ、型のIDは、同じ店舗に属することを確かめる。
