# 競合料金比較記事 調査と執筆計画

## 文書の状態

- 状態: `Active`
- 作成日: 2026-09-28
- 更新日: 2026-11-08（公式ページの照合と記事の改訂）
- 対象: `src/components/features/ArticleSite/content/articles/shift-management-pricing-comparison/`、`public/llms.txt`、`public/sitemap.xml`、`public/ogp/articles/`
- 現在の正本: 記事本文と、シフトリの料金・上限は下記の参考ファイル

この文書は、「エアシフト 料金」「らくしふ 料金」で検索する店長に向けた料金比較記事について、競合の料金調査の結果と、記事を書くときの判断を残す記録である。  
現在仕様の正本ではない。  
料金は変わるため、記事を更新するときは、この文書の数値ではなく各社の公式ページを確認し直す。

## 決定事項

- 比較対象はAirシフト、らくしふ、シフオプとシフトリの4つとする。  
  LINE WORKSの「シフト管理」アプリ（β版、無料）は月額の表に入れず、違いの説明と「向いている店」の候補に使う。
- らくしふは、公式の料金ページで月額を公開していないため、月額の表から外す。  
  見出しは検索する人の問いに合わせて「らくしふの料金」とし、公式ページで確認できた条件から書く。
- 比較の人数は「店長を含む合計10・15・20・25・30・40・50名の1店舗」とする。  
  2026-09-28の初版は10〜25名で、シフトリが全ケースStandardに収まる範囲だった。  
  比較の範囲をシフトリに有利な人数に限ったと受け取られないよう、2026-11-08にPro（月額3,480円、税込、ユーザー確認）の範囲まで広げた。
- 各社の課金対象の数え方が違うため、店長は管理画面でシフトを作る人とし、Airシフトのスタッフ用アプリとは連携しない前提で試算する。
- シフオプの金額は、料金ページの表示のまま載せる。  
  基本プランに税込・税別の記載がないため、税込換算はしない。  
  税別の場合はAirシフトと同じ税込額になることを、表の下に書く。
- 公式ページに記載がない項目は、表で「記載なし」と書く（初版の「不明」から変更）。
- シフトリの制約（勤怠・給与計算・自動作成がないこと、利用人数の上限、Freeプランへの移行）は「シフトリを選ぶ前に確かめたいこと」にまとめ、他の節で繰り返さない。
- Hero画像は新規生成せず、`free-shift-tool-selection`の`hero.webp`を複製して使う（2026-09-28、ユーザー指示）。

## 調査の方法

初版（2026-09-28）は、実行環境から各社の公式ページへ直接アクセスできなかった（WebFetchは`EGRESS_BLOCKED`、curlは`CONNECT tunnel failed, response 403`）。  
そのため、検索対象を各社の公式ドメインに限定したWeb検索を行い、検索結果に含まれる本文抜粋で数値と条件を確認した。

2026-11-08に、Claude Codeの内蔵ブラウザで下表の各URLを直接開き、本文と画像の代替テキストから数値と条件を照合した。  
初版から変わっていた点は、記事とこの文書の両方へ反映した。  
比較メディア（PRONIアイミツ、BOXIL、ITreviewなど）は出典にしていない。

## 人数別の試算

前提は、1店舗で店長1名とスタッフが働き、店長を含めた合計がN名の店である。  
店長は管理画面でシフトを作り、Airシフトのスタッフ用アプリとは連携しない。

| 店長を含む合計 | シフトリ | Airシフト（連携スタッフ数×330円、税込） | シフオプ（ユーザー数×300円、税区分の記載なし） |
|---|---|---|---|
| 10名 | ¥1,880（Standard） | ¥2,970（9名） | ¥2,700（9名） |
| 15名 | ¥1,880（Standard） | ¥4,620（14名） | ¥4,200（14名） |
| 20名 | ¥1,880（Standard） | ¥6,270（19名） | ¥5,700（19名） |
| 25名 | ¥1,880（Standard） | ¥7,920（24名） | ¥7,200（24名） |
| 30名 | ¥3,480（Pro） | ¥9,570（29名） | ¥8,700（29名） |
| 40名 | ¥3,480（Pro） | ¥12,870（39名） | ¥11,700（39名） |
| 50名 | ¥3,480（Pro） | ¥16,170（49名） | ¥14,700（49名） |

- Airシフトは、店長もスタッフ用アプリと連携する場合、330円（税込）が加わる。
- シフオプは、管理者のアカウントが課金対象になる場合、300円が加わる。  
  税別の場合の税込額は、1人あたり330円となりAirシフトと同じになる。
- シフトリは、店長を含む利用人数が26名以上でPro、51名以上では利用できない。

## 判断に迷った点

- Airシフトの無料期間後の扱いは、料金ページに「すべての機能が利用できません」、FAQに「ダウンロード以外のすべての機能がご利用いただけなくなります」とある。  
  記事では、条件をより具体的に書いている`A2`の記述を採用した。
- らくしふの無料期間は、初版の検索抜粋にはあったが、2026-11-08の公式ページでは確認できなかった。  
  確認できない条件は書かない方針に従い、「記載なし」とした。
- Airシフトの最低料金（2名以下は990円）は、比較人数では発生しないが、小規模店の読者が誤解しないよう本文に含める。
