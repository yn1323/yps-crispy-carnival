# ポジション割当を範囲選択方式に変更

作成日: 2026-11-19  
状態: Active（2026-11-19にrepositoryへ実装。対象は時間指定のPCの日別表示だけ）

シフト表の「くわしく」表示で、ポジションと休憩の入れ方を変える。  
先にポジションを選んでからバーをなぞる形をやめ、バーの範囲を選んでから、その場のメニューでポジションを選ぶ形にする。

## 1. 対象

今回変えるのは、時間指定の募集のPCの日別表示だけである。  
はじめは「くわしく」表示だけを変えたが、「シンプル」表示も同じ操作にそろえた（2026-11-19、ユーザーの指示）。

| 画面 | 今回 |
|---|---|
| 時間指定のPCの日別表示（くわしく、編集できる） | 範囲を選んでメニューで選ぶ形に変える |
| 時間指定のPCの日別表示（シンプル、編集できる） | 同じ形に変える。休憩もバーに出し、入れられるようにする |
| 時間指定のPCの日別表示（閲覧専用） | 勤務のバーを押して開く欄を、勤務時間と休憩を読むだけの内容にする |
| パターン選択、日付選択 | 変えない。「入れるもの」を先に選ぶ形のまま |
| スマートフォン | 変えない |

## 2. 調査結果

### 今の操作（時間指定のPCの日別表示）

| 操作 | 今の動き |
|---|---|
| 空いている場所をドラッグ | 勤務を新しく入れる。ポジションは「入れるもの」で選んだもの |
| バーの端をドラッグ | 時間を変える。隣り合う区間の境目は両方が同時に動く。押した時点で、ほかの操作より先に判定する |
| バーの本体をドラッグ | 移動ではない。なぞった範囲を、選んだポジションで上書きする |
| バーの本体を押す | 勤務の欄が開く。区間ごとの時間、削除、ポジションの変更、休憩の変更がある |
| 「休憩」を選んでいる間 | バーの上をなぞると15分単位で休憩が入る。この間は勤務の追加と時間の変更ができない |

バーの本体のドラッグに「移動」は割り当たっていないため、範囲選択とはぶつからない。  
ぶつかるのは、バーを押して開く勤務の欄である。  削除と休憩の時刻変更の入口がここにしかないため、新しいメニューに残す（2026-11-19、ユーザーの判断）。

### 区間の持ち方と保存の流れ

- 勤務は1人1日ごとの`ShiftData.positions`に、ポジション、開始、終了を持つ区間の配列で持つ。
- 休憩は区間の配列に入れず、同じ日の`ShiftData.breaks`に開始と終了で持つ（3件まで）。  表示、集計、保存のときに、勤務の内側へ切り詰める。
- 操作はJotaiの下書き（`shiftDraftsAtom`）を書き換える。  `ShiftForm`が`onShiftsChange`で画面の外へ知らせ、「下書き保存」と「確定」で`saveShiftAssignments`へ全件を送る。

今回の変更は下書きの書き換えまでで、保存する形と保存の流れは変えない。

### 新しいバーの初期ポジション

今は「入れるもの」で選んだポジションで、選んでいなければ店舗の既定のポジションである。  
既定のポジションは店舗に1件あり、最初は店舗を作ったときにできるポジションである。  どれが既定かは画面に出ない。  
スタッフに主ポジションの情報はない（担当外、見習い、リーダーだけを持つ）。

### スナップ単位

勤務は30分、休憩をなぞるときだけ15分である。

## 3. 仕様

### 範囲を選ぶ

- 勤務のバーの内側をドラッグすると、その時間の範囲を選ぶ。  30分単位にそろえ、押したひと続きの勤務の外へは出ない。
- ドラッグせずに押した場合は、押した区間の全体を選ぶ。  区間はポジションの境目と休憩で区切る。  休憩を押した場合は、その休憩を選ぶ。
- バーの端と、隣り合う区間の境目は、今までどおり時間の変更になる。  この判定は範囲選択より先に行う。
- 選んだ範囲は半透明の面と枠線で示す。
- 空いている場所をドラッグすると、今までどおり勤務が新しく入る。

### メニューで選ぶ

選択が決まると、選んだ範囲のすぐ上にメニューを出す。

| 項目 | 選んだときの動き |
|---|---|
| ポジション（色の丸と名前） | 選んだ範囲をそのポジションにする。区間は必要に応じて分け、隣り合う同じポジションの区間は1つにまとめる |
| 休憩 | 選んだ範囲を休憩にする。勤務の頭かお尻にかかる場合は、休憩を残さず勤務を短くする（今の決まりのまま） |
| 休憩を時刻で追加 | 休憩の編集を開く。15分単位の休憩はここから入れる。休憩だけを選んでいる間は、項目の名前を「休憩を時刻で変更」にする。どちらも同じ編集を開き、その日の休憩をすべて足し引きできる（2026-11-19、ユーザーの指示） |
| 削除 | 選んだ範囲にかかる勤務の区間を、区間ごと削除する。項目には「勤務 10:00〜16:00を削除」のように、削除する時間を書く |

- 選んだ範囲がすべて同じポジションなら、そのポジションにチェックを出す。  すべて休憩なら「休憩」にチェックを出す。
- 休憩をまたいでポジションを選んだ場合は、休憩を残してポジションだけを変える。
- 休憩だけを選んでポジションを選んだ場合は、その休憩を外し、選んだポジションの勤務にする。
- 休憩だけを選んで、チェックの出ている「休憩」をもう一度選んだ場合は、その休憩を外す。勤務は変えない。
- ひと続きの勤務の全体か、ポジションの区間の全体を選んでいる間は、「休憩」を選べない。  項目の下に「まるごと休憩にはできません」と出す。
- メニューを開いている間は、1〜9のキーで、表示順のポジションを選べる。
- Esc、メニューの外を押す、別のバーの操作を始める、表をスクロールする、のどれかで、何も変えずに閉じる。
- ポジションを分けていない店舗では、ポジションの代わりに「勤務」を出す。  休憩を選んで「勤務」を選ぶと、休憩が外れる。

### 入れるものの選択と案内

日付の見出しの右の「入れるもの」は、次に新しく入れるものを選ぶ場所にする（2026-11-19、ユーザーの指示。はじめは押せない凡例にしたが、押して切り替えられる形に変えた）。

- ポジションを押すと、次に新しく入れる勤務のポジションが変わる。
- 「休憩」を押すと、勤務のバーの上をなぞった範囲が、メニューを開かずに15分単位で休憩になる。  この間は、勤務の外をなぞっても何も入らない。
- 休憩を選んでいる間も、なぞらずに押した場合は、押した区間のメニューを開く。  バーの端のドラッグも、時間の変更のままにする。
- 選んでいるものは薄い塗りで示す。  ポジションはそのポジションの色、休憩は灰色にし、枠は付けない。
- 横に「バーをなぞると ポジションを変えられます」と出す。  ポジションを分けていない店舗では「バーをなぞると 休憩を入れられます」にする。
- ポジションか休憩を一度入れたら、案内を出さない。  端末（localStorage）に覚える。

### 新しいバーの初期ポジション

「入れるもの」で選んでいるポジションを、次に新しく入れる勤務に使う。

| 操作 | 選択 |
|---|---|
| 日付の見出しのポジションを押す | そのポジションになる |
| 勤務のバーのメニューでポジションを選ぶ | そのポジションになる。休憩を選んでいた場合は、休憩の選択が外れる |
| 日付の見出しの「休憩」を押す | 休憩になる |
| 勤務のバーのメニューで「休憩」を選ぶ | 変わらない |

- 選んだポジションは、店舗ごとのキー（`shiftori:shiftBoard:lastPosition:{shopId}`）で、端末（localStorage）にも覚える。
- 何も覚えていない場合と、覚えたポジションが削除済みの場合は、ポジションの一覧の先頭を使う。  既定のポジションは画面から分からないため使わない（2026-11-19、ユーザーの指示）。
- 休憩の選択は端末に覚えない。  開いた直後に勤務を入れられない状態を避けるためである。
- 「シンプル」表示とポジションが1つの店舗では、ポジションを選び分けないため、今までどおり既定のポジションを使う。

選択は、ほかの表示の「入れるもの」と同じ状態（`selectedPositionIdAtom`、`breakToolActiveAtom`）に持つ。  
時間指定のPCの日別表示を開いた時点で、覚えたポジションか一覧の先頭を、この状態へ入れる。  
主ポジションの新設は範囲外とする。

### スタッフ名の横の表示

スタッフ名の横の「担当外」「リーダー」は、「入れるもの」で選んでいるポジションでの値を出す。  今までの決まりと同じである。

### 「シンプル」表示

「シンプル」表示でも、勤務のバーの範囲を選ぶと同じメニューを開く（2026-11-19、ユーザーの指示）。

- 時刻で入れた休憩を、「シンプル」表示でも勤務のバーに出す。  「くわしく」で入れた休憩が、切り替えると見えなくなるのを防ぐ。
- メニューには、ポジションの代わりに「勤務」を出す。  休憩を選んで「勤務」を選ぶと、休憩が外れる。  ポジションが1つの店舗の「くわしく」表示も同じである。
- 押して選ぶ区間と、削除の対象は、ポジションの境目で区切らない。  ポジションだけが違う隣り合う勤務を、続いた1つの勤務として扱う。
- 「入れるもの」は出さない。  空いている場所をドラッグして入れる勤務は、今までどおり既定のポジションで入る。
- 店舗の休憩の決まりから休憩の初期値を入れる動きは、今までどおり「くわしく」表示だけにする。
- スマートフォン、一覧、パターン選択、日付選択の「シンプル」表示は変えていない。  これらは、今までどおり休憩を出さない。

編集できる表示では勤務の欄を開かなくなるため、勤務の欄から、希望時間、未提出の表示、削除を消した。  勤務の欄は閲覧専用の表示でだけ開く。

### 勤務と勤務の間の空き

勤務を離して入れると、間の空きを休憩の斜線で見せる。  内部では勤務が2つあるだけで、休憩としては持っていない。  
この空きも、休憩と同じように押して選べるようにした（2026-11-19、ユーザーの指示）。

- 空きを押すと空きの全体を選び、空きの中をドラッグするとその範囲を選ぶ。
- メニューの「休憩」にチェックを出す。
- ポジションを選ぶと、そのポジションの勤務で埋める。
- 「勤務」か、チェックの出ている「休憩」を選ぶと、直前の勤務と同じポジションの勤務で埋める。
- 空きには削除の項目を出さない。

空きは、内部でも休憩として持つ（2026-11-19、ユーザーの指示。「バーの表記に合わせる」）。

- 勤務のある日に離れた時間の勤務を入れる、間の区間を削除する、勤務の長さを変える、のどれかで空きができた場合は、空きを直前の勤務と同じポジションの勤務で埋め、その時間を時刻で入れた休憩にする（`closeGapsWithBreaks`）。
- 最初の開始から最後の終了までがひと続きの勤務になり、保存、通知、出力でも、休憩のある1つの勤務として扱う。
- 前から空きのあった日は、時間指定のPCでその日の勤務を変えた時点で置き換える。  表示しただけでは置き換えない。
- 休憩の編集の「勤務」の欄は、ひと続きの勤務ごとに出す。  ポジションの境目では区切らない。
- スマートフォンの編集と、パターン選択、日付選択は変えていない。  スマートフォンで勤務を離して入れた日は、空きのまま残る。

### 休憩の件数

画面では、休憩の件数を制限しない（2026-11-19、ユーザーの指示）。  
「休憩は3件まで入れられます」の知らせと、休憩の編集で追加を止める動きを消した。  
保存のAPIの上限（`SHIFT_ASSIGNMENT_BREAK_LIMIT`）は、負荷を防ぐ値として、1つの勤務につき3件から20件へ上げた。

### 休憩の端を動かす

休憩の開始か終了の近くをつまんで、休憩の時間を動かせるようにした（2026-11-19、ユーザーの指示）。

- 15分単位で動かす。  動かす端は勤務の開始より後、終了より前に収める。
- 反対の端まで動かして、休憩が15分より短くなる場合は、その休憩を削除する（2026-11-20、ユーザーの指示。はじめは15分で止めていた）。
- ほかの休憩と重なった場合は、1つにまとめる。
- 休憩はバーの上に重ねて出すため、休憩の端を、勤務の端より先に判定する。
- 短い休憩でも中央を押して選べるよう、端として扱う幅は休憩の幅の3分の1までにする。
- 動かさずに離した場合は、その休憩を選び、メニューを開く。

### ドラッグ中の休憩と、勤務の外に出た休憩

- 勤務の長さを変えている間も、休憩をバーに出し続ける。  はじめは、ドラッグ中は休憩を描いていなかった。
- 勤務を変えた時点で、勤務の外に出た休憩と、勤務の頭かお尻にかかった休憩を取り除く（`pruneBreaks`）。  取り除かないと、勤務を縮めてから伸ばし直したときに、消えたはずの休憩がまた出る（2026-11-19、ユーザーの指摘）。

### 休憩の編集での重なり

休憩の編集で、時刻の重なる休憩を入れた場合は、いちばん早い開始からいちばん遅い終了までの1つの休憩にまとめて入れる（2026-11-19、ユーザーの指示）。  
はじめは「休憩の時間帯が重なっています」と出して止めていた。  まとめた結果が勤務の開始か終了に接する場合は、今までどおり止める。  
この編集は、スマートフォン、パターン選択、日付選択でも同じものを使うため、どの表示でも同じ動きになる。

### 休憩の見た目

- 時刻で入れた休憩は、ポジションの色を隠し、勤務の間の空きと同じ灰色の斜線で示す。  休憩はポジションではないためである。
- 勤務の間の空きをはさむバーは、空きの側の角を丸めない。  休憩を勤務の内側へ入れた場合と、形をそろえる。
- 選んだ範囲の枠線は、薄い灰色にする。

## 6. 初めて使う人の視点での確認（2026-11-19）

実装のあとで、経緯を知らない立場のエージェントに実画面を操作させた。  指摘のうち、次の3点を直した。

- 休憩のやめ方が読み取れない。  チェックの出ている「休憩」をもう一度選ぶと外れるようにした。
- 削除の項目が何を消すのか読み取れない。  項目名を「勤務 ◯◯を削除」にした。
- 「休憩」を選べない理由が出ない。  項目の下に理由を出した。

直していない指摘は次のとおりである。  どれも、今回変えた範囲の外にある今の動きか、決めが要るものである。

- 区間の境目のすぐ横からなぞると、範囲選択ではなく境目の移動になる（端の判定は左右10px）。
- 勤務を区間ごと削除したあとで勤務を延ばすと、範囲の外に残っていた休憩がまた表示される。  → その後、勤務を変えた時点で取り除く形に直した。
- 勤務のない行で、最初に何をすればよいかの案内がない。
- 勤務の頭かお尻を選んで「休憩」にすると、知らせなしに勤務が短くなる。
- 「休憩を時刻で追加」は、選んでいた範囲を初期値にしない。
- その日の勤務をまとめて消す項目がない。

## 7. 次の段階

- スマートフォン: 区間を押したら、その区間の全体を対象に、同じ選択肢をボトムシートで出す。  ドラッグでの範囲選択はしない。
- スマートフォンで区間の途中から切り替える操作（時刻を指定して分ける）。
- パターン選択と日付選択の「入れるもの」をどうするか。
- 主ポジションを持たせ、新しいバーの初期ポジションに使うか。
- パターン選択、日付選択、スマートフォンの「入れるもの」でも、選んだポジションを端末に覚えるか。

## 8. 範囲外

- 充足度（必要人数）の表示
- バーの削除と分割による勤務の分離
- 主ポジションのマスタ追加
